# PromptForge AI – dashboard

Next.js dashboard for the PromptForge backend: submit a problem, watch the agents work live (SSE),
and inspect the verdict matrix, tests, routing decisions, model telemetry and run history.

```bash
npm install
cp .env.example .env.local   # point NEXT_PUBLIC_API_URL at the backend
npm run dev                   # http://localhost:3000
```
